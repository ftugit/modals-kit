# План: двойное закрытие модалок на мобильных + меню пользователя всплывашкой на десктопе

Заказ владельца (этот ход):
1. Модалка на мобильной версии «закрывается дважды»: анимация закрытия, потом
   содержимое мигает и пропадает окончательно. Проверить и починить.
2. `user.menu`: на ПК (десктоп) переделать модалку во всплывашку (popover).
   Конкретно этому меню URL не нужен. Мобильная версия — как прежде (модалка).

## Диагноз (подтверждено пробой, мобильный вьюпорт 390×844)

Хост модалок (`ModalHost.svelte`) на закрытии последней записи меняет живое
дерево `Layers` на заново монтируемый `ExitContent` (снапшот `shown`).
Таймлайн пробы: `t≈43мс` после клика закрытия слой перемонтируется
(идентичность узла меняется), один кадр содержимое пустое, затем то же
содержимое монтируется заново и проигрывает reveal внутри уезжающей оболочки.
На десктопе смена поддерева маскируется короткой scale-анимацией, на
мобильном (крупный sheet-выезд) видна как «закрылось → мигнуло → закрылось».

## Приёмка

- M1: закрытие на мобильном — без перемонтирования содержимого: тот же DOM-узел
  слоя от открытия до снятия, без пустого кадра, без повторного reveal.
- M2: десктоп (≥ breakpoint хоста): клик по аватару открывает всплывашку у
  кнопки; адрес не меняется (`?modal=` не появляется); Esc/клик мимо закрывают;
  «Изменить профиль» открывает модалку входа как прежде; «Выйти» работает.
  Мобильная ширина: прежняя модалка `user.menu` с URL. Без JS: ссылка ведёт на
  страницу `/user/menu`, как сейчас.
- M3: гейты — svelte-check, unit (modals/user), браузерные пробы обеих веток.
- Коммиты только локальные; push — по отдельному указанию владельца.
