- **Проблема:** сейчас дубль «от/до» снимается regex'ом по суффиксу ` · от/до`.
- **Цель:** брать базовую подпись из схемы/описания и строить направление только в `combinedLabel`.
- **Файлы:** `ActiveFilters.svelte`, `view.ts`, `filters.ts`.

### 2. Реактивность notice в открытом popup
- **Ценность:** средняя.
- **Проблема:** если `notice` меняется или исчезает при открытом popup, `aria-describedby` может остаться устаревшим до закрытия.
- **Цель:** синхронизировать ARIA при изменении notice или переоткрывать popup.
