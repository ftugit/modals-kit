# Хвосты: что не сделано

Единственный сводный файл про незакрытое. Здесь отложенные задачи и памятки
по решениям владельца. Принятые решения живут в коде и в [`docs/design/`](./design).
Закрытые планы и аудиты в дереве не хранятся: контракт уже в README рядом с
кодом, полный текст — в git.

Обозначения: **P1** — блокирует обещанное поведение, **P2** — заметно
пользователю, **P3** — отложенный функционал без срочности, **P4** — гигиена.

---

## 1. В планах

- **Системный контекст — P3, раньше сессий** ([`docs/plan-system-context.md`](./plan-system-context.md)):
  известное сделано локально, не закоммичено: `get`/`markDeleted` и конфиг принимают `ctx`, слот и удаление сервера идут от актора. Сессии и три открытых вопроса в плане не начаты.
- **Сессии — P3** ([`docs/plan-sessions.md`](./plan-sessions.md)):
  этапы 1–2 закоммичены (`851c5d7` права, `458aea2` прямые функции без `jti` снаружи). Не начаты экран своих устройств и журнал чужих сессий. `server` остаётся фаерволу куки, не всему порту.
- **Хранилище и раздел «Облако» — P3** ([`docs/plan-storage.md`](./plan-storage.md)):
  библиотека `#lib/storage` и пул серверов уже есть. Не начаты дедупликация по хешу, два серверных режима клонирования, счётчик пропавших файлов и самореферентная модель «Облака» поверх обезличенного `storage_file`.
- **Крон-подсистема — P3** ([`docs/plan-cron-app.md`](./plan-cron-app.md), [`docs/plan-cron-worker.md`](./plan-cron-worker.md)):
  декларативная схема задач внутри приложения и отдельный оркестратор на Hono. Кода нет.

## 2. Отложено владельцем

- **Фоновая серверная конвертация несжатых аватаров без JS — P3** ([`docs/plan-queue.md`](./plan-queue.md)):
  не раньше полноценной подсистемы очередей.
- **Исполнитель отложенных удалений аккаунтов (`sweepDeletions`) — P3**:
  фонового планировщика в проекте нет; вызов по расписанию отложен.
- **Калибровка маршрутных бюджетов `npm run test:size` и вторая локаль интерфейса — P4**:
  отложены. Контракт ошибки «код + текст» уже в [`docs/design/errors.md`](./design/errors.md).
- **Оболочка списков — сделана локально, не закоммичена** ([`docs/design/lists.md`](./design/lists.md)):
  `Listing` в `src/components/listing/`. Seed и блокировки на ней. Кнопка фильтров и поиск зафиксированы внутри экрана, в шапку сайта не выносятся.
- **Демо `/fields` (`base64`-превью файла) — закрыто без правок**:
  учебный раздел, файл в нём — пример контрола.

## 3. Исключительно по обращению

- **Расширения `#lib/db` (generic REST, таблица ручных SQL-миграций `kit_migration`, вычисляемые поля)**:
  не считаются очередным планом. Архитектура — один проект, без внешнего generic REST.
- **Время жизни WebSocket-загрузки**: исследование 2026-11-03 закрыто, реализация не заказана. HTTP-предвалидация не усиливает проверки: права, лимиты и бюджет и так идут после `init`. Дешёвый предел, если работу закажут, — дедлайн от `accept`, а не от `init`; `pong` не должен продлевать простой, пока нет данных. Внешний таймаут прокси Northflank первоисточником не подтверждён. Без отдельной команды код не менять.
- **HSTS `includeSubDomains`**: заголовок в `src/hooks.server.ts` живёт один–два года. Если прокси пропускает его на домен VDS, политика ляжет и на поддомены этого домена. Не менять молча.

## 4. Заметки среды

- **Версия Node.js**: `>=22.17 <25` (`package.json#engines`).
- **Полный прогон vitest** идёт около двух минут на 2 vCPU / 1,9 ГБ RAM. В ходе работы гоняется затронутая область, полный набор — перед финальным коммитом пачки.
- **Браузерные сьюты демо** (`db-demo`, `paginate`, `shikimori` и остальные из `package.json`) появляются вместе с модулем `demo`. Чистое ядро их не содержит; `test/browser/run-all.mjs` берёт только существующие файлы.
