# Хвосты: что не сделано

Единственный сводный файл про незакрытое. Здесь перечислены отложенные задачи и
памятки со статусами по решениям владельца. Принятые проектные решения и объяснения
«почему так» живут в коде и в [`docs/design/`](./design).

Обозначения: **P1** — блокирует обещанное поведение, **P2** — заметно
пользователю, **P3** — отложенный функционал без срочности, **P4** — гигиена.

---

## 1. В планах (памятки без этапов)

- **Сессии и нативные права `user_auth` / `user_session` — P3** ([`docs/plan-sessions.md`](./plan-sessions.md)):
  пользовательский интерфейс активных сессий/устройств с отзывом (модалка + маршрут для себя и чужого аккаунта) и перевод человеческих операций `user.auth.v1` / `user.session.v1` с контекста `SYSTEM` на нативные политики `defineAcl` (`grants`, `checkGrants`, `useGrants`).
- **Хранилище и раздел «Облако» — P3** ([`docs/plan-storage.md`](./plan-storage.md)):
  технический план: строгая граница `#lib/storage` против хуков, дедупликация по включаемому хешу отдельных файлов, два серверных режима клонирования (`clone` + `replicate`) и параллельная раздача реплик, счётчик пропавших файлов с авто-отключением «мёртвых» серверов + софт-удаление серверов + `storage.reconcile`, а поверх обезличенного `storage_file` — самореферентная модель «Облака» (`name`, `auth_id`, `cloud_id`, `file_id`, `visibility`, `access_uids`, `password`) с иерархией `ACL модели + visibility → access_uids → password`.
- **Крон-подсистема: ядро приложения и автономный внешний оркестратор — P3** ([`docs/plan-cron-app.md`](./plan-cron-app.md), [`docs/plan-cron-worker.md`](./plan-cron-worker.md)):
  два связанных плана — декларативная схема задач `CronManifest` (`task` + `payload` + лестница реакций на ошибки `scale` / `steps` / `cancel`) с двухрежимным входом `wss://` + `HTTP POST` внутри нашего приложения и универсальный автономный оркестратор на базе Hono под Cloudflare Workers, бесплатные Docker-сервисы и Google Apps Script.

## 2. Отложено владельцем

- **Фоновая серверная конвертация несжатых аватаров без JS — P3** ([`docs/plan-queue.md`](./plan-queue.md)):
  реализовывать **не раньше**, чем будет сделана полноценная подсистема очередей.
- **Исполнитель отложенных удалений аккаунтов (`sweepDeletions`) — P3**:
  фонового планировщика задач (cron) в проекте пока нет; вызов по расписанию отложен.
- **Калибровка маршрутных бюджетов `npm run test:size` и вторая локаль интерфейса — P4**:
  отложены на потом.
- **Демо `/fields` (`base64`-превью файла в `fields.form.server.ts`) — закрыто без правок**:
  `/fields` — учебный демо-раздел, файл в нём служит просто примером контрола; менять не нужно.

## 3. Исключительно по обращению (вне автоматического плана)

- **Расширения `#lib/db` (generic REST, таблица ручных SQL-миграций `kit_migration`, вычисляемые поля)**:
  по решению владельца помечены **строго исключительно по явному обращению** — автоматически как активный или очередной план работ **не учитываются** (архитектура ориентирована на работу внутри одного проекта без внешнего generic REST).

## 4. Заметки среды

- **Версия Node.js**: `>=22.17 <25` (`package.json#engines`) — удерживает сборку на Node 22 / 24 LTS и не даёт Vercel автоматически поднимать неподдерживаемый в `@sveltejs/adapter-vercel` Node 26+.
- **Полный прогон vitest** идёт ~2 минуты на 2 vCPU / 1,9 ГБ RAM; в ходе работы гоняется затронутая область, полный набор — перед финальным коммитом пачки.
