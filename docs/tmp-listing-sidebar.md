# Временно: фильтр списка в sidebar

Удалить, когда вернёмся к вопросу. Это запись исследования, не план к исполнению и не контракт `Listing`.

## Что решено

Положение фильтра зависит от текущего рендера, не от догадки `Listing`.

- Модалка опцию не передаёт. `Listing` всегда рисует кнопку в `Surface`.
- Страница может передать зону sidebar (`top` / `middle` / `bottom`). Это не обязательно.
- `Listing` смотрит на эту опцию и на общий хук узкого экрана. Зона есть и экран не узкий — форма сразу в sidebar. Иначе кнопка в `Surface`.
- Несколько списков не склеивают фильтры. У каждого своя зона, либо кто-то зону не получает и остаётся с кнопкой.
- `Listing` не вызывает `useModal()` и `tryUsePage()`, чтобы понять, где он. Контекст страницы есть и у модалки: она живёт под тем же layout.

## Цепочка опции

Проп сам не протекает: у каждого узла закрытый список пропов. Его надо объявить и передать дальше.

Страницы:

- `/users` → `SeedUsersList` → `Listing`
- `/blocks` → `BlocksList` → `Listing`
- `/user/[id]/blocks` → `BlocksList` → `Listing`
- `/users/pick` → `UserPicker` → `SeedUsersList` → `Listing`. Если этой странице понадобится sidebar, проп должен пройти и через `UserPicker`: там два списка.

Модалки опцию не передают:

- `SeedUsersModal` → `SeedUsersList`
- `BlocksModal` → `BlocksList`
- `UserPickerModal` → `UserPicker` → `SeedUsersList`

`UserPickerSteps` никуда не подключён.

## Sidebar

Канал уже есть: `useSidebarSlot` / `registerSidebarSlot`, зоны `top` / `middle` / `bottom`, плюс `auto`. `useSidebarSlot` смотрит `enabled` один раз и за шириной не следит. Регистрацию, которая зависит от хука, надо делать через `registerSidebarSlot` внутри эффекта.

`auto` — не зона Listing, а режим `registerSidebarSlot`. Занятость зоны видна по её списку: не-каркасная регистрация. Каркас layout (`frame`) во всех трёх зонах виден, но для `auto` их не занимает. Свободные зоны заполняются сверху вниз, в порядке регистрации `auto`. Нет ни одной занятой зоны — `auto` не рисуется и пишет в консоль браузера `[sidebar] auto: нет занятого слота, блок не показан`. Свободной зоны не осталось — то же молчание в вёрстке и `[sidebar] auto: свободной зоны нет, блок не показан`. Отдельной серверной функции для жалобы нет.

Каркас сам занимает все три зоны копией шапки (пользователь, то же меню, футер). Форма страницы встанет под этим, не вместо. На широком экране панель в документе, на узком это шторка. Порог — `useIsMobile` в `#hooks`: он читает CSS `--mobile`. `ModalHost` ширину не читает, ему передают `isNarrow`.

## Чего не делать

- Не угадывать носитель внутри `Listing`.
- Не объединять схемы фильтров.
- Не класть кнопку в шапку сайта.
- Не учить `Surface` слову «фильтр».

## Этапы

Нарезка и всплывашка `ActiveFilters` — второй этап, не начат. Одна строка на узком экране (`max-lg`, без хука) — уже в компоненте. Провод зоны в `Listing` ещё не делался.
