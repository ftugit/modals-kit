## Согласованное исправление типа `mergeSlot`

Пользователь согласовал исправление публичного TypeScript-контракта. `mergeSlot` возвращает `MergeMarker`, значения ячеек — `SlotValue` (массив или маркер); экспортированы оба типа, ложное приведение удалено. Существующая runtime-семантика сохранена; получение массива — через `renderMergeSlot`, различение — `isMergeSlot`. Миграция и несовместимость для TypeScript-потребителей описаны в `src/components/shell/README.md`. Прежние записи выше о необходимости согласования являются историческими.

- Пробная замена barrel-импортов Button/Fieldset в интеграционной копии не исправила ни один из шести маршрутных бюджетов; эксперимент откатан через git, в demo не перенесён. Последний demo size по-прежнему не проходит: точные значения в `pending.md`.

### PROCEDURE: следующая точка

1. Создать детерминированный браузерный тест заранее загруженного устаревшего снимка без предположения о повторном сетевом запросе при уже существующем preload; покрыть страницу и модальный сценарий. Отследить возможные другие гонки `syncServer` без ослабления отзыва сессии.
2. Диагностировать спорадические R-18, R-24 и R-46 под нагрузкой; не повышать пороги без доказательства. Повторять полноценный браузерный набор, по возможности добавить Firefox/WebKit и desktop-проверку фильтров.
3. Профилировать реальные статические зависимости шести тяжёлых маршрутов, искать изменения, сохраняющие SSR/no-JS, и проверять размеры; текущий эксперимент с прямыми импортами результата не дал. Лимиты менять только с согласия владельца.
4. Повторить все gates после любых следующих изменений; upstream advisories и пропущенные live-проверки остаются в `pending.md`.
