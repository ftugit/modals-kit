# Независимость библиотек от фреймворка и локализация

Вопросы владельца:

1. Не привязаны ли библиотеки `src/lib` к фреймворку, и можно ли повторить их «хуки» в другом фреймворке.
   Проверено симуляцией под React Router (`sim/react-router/`).
2. Живут ли тексты интерфейса в UI или приходят из приложения, чтобы перевод не требовал правки исходников
   библиотек и хуков.

## Метод

- Скан импортов: `svelte`, `svelte/*`, `$app/*`, `@sveltejs/kit` в `src/lib/{address,modals,paginate,form,db,cache,fetch,task}`
  вне папок адаптеров (`svelte/`, `sveltekit/`, `cores/`, файлов `sveltekit.ts`) — **пусто**.
- Чтение адаптеров целиком: `address/sveltekit.ts`, `modals/cores/sveltekit.ts`, `modals/svelte/ModalHost.svelte`,
  `paginate/svelte/PaginatorHost.svelte`, `paginate/sveltekit/router.ts`, `form/svelte/bind.svelte.ts`.
- Симуляция: адаптеры и хуки на React 19 + React Router 8, 15 тестов (`happy-dom`, `createMemoryRouter`), строгая
  проверка типов `tsc` — она прошла по 63 файлам `src/lib`, ни один не Svelte.
- Тексты: `~/.agent/tools/cyr-scan.mjs` по библиотекам, хукам и компонентам, затем чтение каждого места.

## Итог по фреймворку

**Ядра чистые.** Связка с роутером — маленькие интерфейсы: писатель адреса — 4 зависимости, движок модалок
(`ChainEngine`) — 9 полей, роутер пагинатора (`MinimalRouter`) — 3 функции. Все сторы — неизменяемый снимок +
`subscribe`, то есть подходят к React `useSyncExternalStore` без прослоек. `FormStore` даже назван по-реактовски
(`getSnapshot`/`subscribe`). Серверная часть формы (`createFormHandler`) работает с обычным `Request`.

Что мешает переносу — логика, которая живёт в Svelte-файлах, и мелкие дыры в публичном API:

### План правки (общий для всех библиотек)

1. Библиотека отдаёт **код и данные** (`{ code: 'modal.missing', name }`, `{ mode: 'not' }`, `{ step: 2, total: 4 }`), а не готовую фразу.
2. Тексты — словарь кодов, как в `form/messages.ts`: русские значения по умолчанию лежат в UI (`components/*`), приложение
   передаёт свой словарь один раз (настройка/контекст) или частично переопределяет.
3. Порядок: модалки (загрузчик + хост) → ссылки и хуки → задача/адрес → фильтры (после решения владельца по подписям) →
   `validate.ts`/`external.ts`.
4. Проверка: `cyr-scan` по `src/lib/{address,modals,paginate,form,task,db}` и хукам — пусто вне словарей по умолчанию.

Решение по подписям фильтров ждёт владельца (варианты — в отчёте хода, где сделан этот аудит).
