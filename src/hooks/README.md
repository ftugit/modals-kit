# `src/hooks` — связки между библиотеками и средой

Библиотеки в `src/lib` не знают друг о друге: у каждой своё чистое ядро без чужих импортов (`tooling/core-purity.mjs`). Когда двум библиотекам или библиотеке и серверному конвейеру SvelteKit нужно работать вместе, переходник пишется **здесь**, а не внутри одной из них — оба ядра остаются переносимыми по отдельности.

---

## Состав папки

| Модуль | Что соединяет | Роль |
|---|---|---|
| `cache-db.ts` | `#lib/cache` × `#lib/db` | Общее между инстансами KV-хранилище в PostgreSQL (`pgStore`, ресурс `cacheKv` → таблица `public.cache_kv`), часы базы (`clock_timestamp()`), атомарные `add`/`incr` и оппортунистическая вычистка просроченных строк. В приложении экземпляр экспортируется как `sharedStore` из `src/lib/server/cache.ts`. |
| `db-form.ts` | `#lib/db` × `#lib/form` | Вывод параметров и валидаторов полей формы из дескриптора ресурса БД (`formParams(resource)`), включая доказательство полноты правил `rulesFrom` для `pick`. |
| `component-form/` | `#lib/form` × SvelteKit `Handle` / `$app/state` | Маршрутно-независимые формы компонентов: компонент со своей формой (`SeedForm`, `ProfileForm`, `MenuBody`) монтируется на любой странице или в модалке без дублирования `actions` в каждом `+page.server.ts`. |

---

## Папочный модуль `component-form/`

Многофайловые хуки оформляются отдельной папкой с чётким разделением клиентской и серверной точек входа:

- `index.ts` — публичный клиентский вход (`bindComponentForm`, типы `ComponentFormOptions`).
- `client.svelte.ts` — привязывает `<Form>` и `kitActionTransport` к текущему видимому адресу (`visibleAddress().url`) и автоматически подхватывает одноразовый `page.data.formResult` своего `formId` после нативного `POST` без JS.
- `server.ts` — `registerComponentForm(reg)` и `componentFormsHandle`:
  - `GET` и чужие `POST` проходят в `resolve(event)` без накладных расходов;
  - с JS (`Accept: application/json`) возвращает `{ data: { result } }` со статусом обработчика и выставленными `Set-Cookie`;
  - без JS при успехе делает `303 See Other` (или рендерит ответ в том же запросе при `'inline'`);
  - без JS при ошибке рендерит текущую страницу прямо в ответе на этот же `POST` с кодом ошибки (`422` и др.) и `locals.formResult = result`, сохраняя введённые значения.
- `types.ts` — контракты регистрации и опций.

## Правило добавления новых связок

- Одиночный компактный переходник без внутренних подмодулей — один файл `src/hooks/<имя>.ts` (и `<имя>.test.ts` рядом).
- Связка из нескольких файлов (раздельные `client` / `server` / `types`) — отдельная папка `src/hooks/<имя>/` с явными точками входа.
- Внутри `src/hooks/` нет визуальной разметки и доменных текстов: разметка и домен живут в `src/content/<модуль>/` и `src/lib/components/`.
