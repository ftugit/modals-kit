# src/hooks — где lib соединяются

Библиотеки в `src/lib` — независимые ядра: друг друга они не импортируют
(совместимость держат структурные контракты и тесты договорённостей).
Код, который по смыслу соединяет две библиотеки, живёт здесь — в
приложении, а не в одной из них. Импорт: `#hooks/<имя>.js`.

Что здесь:

| Файл | Соединяет | Что |
|---|---|---|
| `db-form.ts` | lib/db × lib/form | `formParams(resource)` — параметры полей формы из правил модели БД |
| `cache-db.ts` | lib/cache × lib/db | `pgStore(db)` — общее Postgres-хранилище контракта cache; модель `cacheKv` |

Правила зоны:

- Сюда можно импортировать любые lib — это и есть назначение папки.
- Обратно нельзя: ни одно ядро в `src/lib` не импортирует `#hooks`
  (зависимость только приложение → библиотеки).
- Файл называется по паре, которую соединяет (`db-form`, `cache-db`).
- Не путать с `src/lib/hooks` — там Svelte-хуки кита (гидратационный
  гейт, drawer), к этой папке отношения не имеют; и с
  `src/hooks.server.ts` — хуком SvelteKit.
