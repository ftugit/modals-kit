# `src/components/paginator` — UI-компоненты пагинатора

Папочный модуль визуализации поверх `#lib/paginate/svelte/index.js`: собирает `PaginatorHost`, списочную (`PageList`) и колоночную (`PageColumns`) раскладки, разделители страниц (`PageDivider`), плашку активного среза выдачи (`PageSlice`), панель настроек (`PaginatorSettings`), поисковую строку (`SearchBar`) и фильтры (`FiltersPanel`).

---

## Состав модуля

| Файл | Назначение |
|---|---|
| `Paginator.svelte` | Единый контейнер списка/карточек со слотами `toolbar`, `header`, `beforeItems`, `afterItems`, `footer`, `empty`, `nav` и настройкой плашки среза `slice`. |
| `ui/PageSlice.svelte` | Уведомление об активном срезе выдачи (`Отображается срез от <TimeAgo />, сбросить?`) с прогрессивным улучшением ссылки/кнопки сброса. |
| `ui/PageDivider.svelte` | Разделитель групп страниц в потоке: на странице `1` не выводит `страница 1`, рендеря вместо неё `PageSlice` (при активном срезе); на страницах `>= 2` выводит `страница N (count)` (и `PageSlice` при принудительном `enable={true}`). |
| `ui/PageList.svelte` / `ui/PageColumns.svelte` | Отрисовка групп страниц списком или round-robin колонками. |
| `ui/PageNav.svelte` / `ui/ResetButton.svelte` | Номерная навигация и сброс позиции/среза с поддержкой работы без JavaScript. |
| `slice.ts` | Чистые функции извлечения ISO-метки среза (`sliceAt` / `asof` / `begAt`), расчёта видимости и прогресса скрытия при прокрутке. |
| `variants.ts` | Варианты оформления контейнера хоста и плашки `PageSlice` (`/* @unocss-include */`). |

---

## Плашка среза выдачи (`PageSlice`)

Извлекает метку времени активного среза из `state.extra` (`sliceAt`, постраничный `asof` вида `<ISO>|<id>` или курсорный `begAt`), отображает живое человеческое время через `TimeAgo` (`#components/ui/index.js`) и контрол сброса (`useLinkTo('reset', ...)` + `reset()`).

### Опции `PageSlice`

- `name?: string` — идентификатор пагинатора (необязателен внутри `PaginatorHost`).
- `enable?: boolean` — принудительный режим снаружи:
  - `true` — отображает плашку при наличии активного среза в обход сценария `firstPageOnly` (например, в раскладке карточек `layout="columns"` или в режиме одной страницы `mode="single"`);
  - `false` — принудительно скрывает плашку;
  - `undefined` — видимость определяется сценариями ниже.
- `firstPageOnly?: boolean` — показывать только на 1-й странице.
- `floating?: 'top' | 'bottom' | false` — плавающее облако сверху или снизу прокручиваемой области. Допустимо **только когда компонент находится внутри `PaginatorHost` и родитель определяется контекстом без указания `name`**.
- `hideOnScroll?: boolean` — постепенное плавное скрытие при прокрутке по направлению потока (с `ResizeObserver`, `data-progress` и дотягиванием `260ms`):
  - в режиме чата (`topTrigger="chat"` или `bottomTrigger="chat"`) скрывается при скролле **вверх**, раскрывается при скролле **вниз**;
  - во всех остальных режимах скрывается при скролле **вниз**, раскрывается при скролле **вверх**.
- `jsOnly?: boolean` — не рендерить плашку при отсутствии JavaScript (на SSR / до гидрации).
- `class?: string` — пользовательские классы поверхности (в том числе для оформления облаком вне 1-й страницы).
