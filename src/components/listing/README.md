# `Listing`

Экран списка без модели. Контракт — [`docs/design/lists.md`](../../../docs/design/lists.md).

Доменный список регистрирует пагинатор, передаёт роут, карточку и `rowAttrs`. Оболочка держит шапку `Surface`, кнопку фильтров, поиск, ленту и ожидание. Поиск всегда над лентой. Зона sidebar передана и `useIsMobile()` равен `false` — форма в этой зоне, кнопки нет. Хук стал `true` — слот снимается. Иначе кнопка в `controls`. Списка активных фильтров нет, только счётчик на кнопке.
