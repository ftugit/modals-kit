# `Listing`

Экран списка без модели. Контракт — [`docs/design/lists.md`](../../../docs/design/lists.md).

Доменный список регистрирует пагинатор, передаёт роут, карточку и `rowAttrs`. Оболочка держит шапку `Surface`, кнопку фильтров, поиск, ленту и ожидание. Кнопка фильтров всегда в `controls` своего `Surface`, поиск всегда над лентой. Списка активных фильтров нет, только счётчик на кнопке. Переноса этих трёх мест наружу нет.
