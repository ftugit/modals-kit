# `Listing`

Экран списка без модели. Контракт — [`docs/design/lists.md`](../../../docs/design/lists.md).

Доменный список регистрирует пагинатор, передаёт роут, карточку и `rowAttrs`. Оболочка держит шапку `Surface`, кнопку фильтров, поиск, ленту и ожидание. Поиск всегда над лентой. Зона sidebar передана и есть контекст страницы — форма в этой зоне с offset `999`, на любой ширине. На `max-lg` форма скрыта, кнопка в `controls` видна (`lg:hidden` на широком). Иначе только кнопка. Между поиском и лентой — чипы активных фильтров: те же ключи, что у счётчика. Подписи приходят от списка, из описания его формы. Чип снимает значение. Метка открывает нарезанный блок, только если форма смонтирована.
