# `Listing`

Экран списка без модели. Контракт — [`docs/design/lists.md`](../../../docs/design/lists.md).

Доменный список регистрирует пагинатор, передаёт роут, карточку и `rowAttrs`. Оболочка держит шапку `Surface`, кнопку фильтров, поиск, ленту и ожидание. Поиск всегда над лентой. Кнопка фильтров — в `controls`, пока страница не передала зону sidebar и ширина не прочитана как широкая. Тогда оболочка регистрирует сниппет формы в эту зону и кнопку не рисует. Без JS и до чтения `--mobile` кнопка остаётся. Списка активных фильтров нет, только счётчик на кнопке.
