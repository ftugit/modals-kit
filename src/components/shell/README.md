# `src/components/shell` — каркас приложения, шапка и реактивный стек SEO

Проектно-независимый модуль оболочки интерфейса: раскладка `AppShell` с нативным мобильным меню без JavaScript, сворачивающаяся при прокрутке многорядная шапка `CollapsingHeader`, контекстные слоты шапки/боковой панели и единый стековый контур метаданных документа (`useHeadSeo`, `PageHead`, `PageTitleSlot`).

---

## Состав модуля

| Файл | Назначение |
|---|---|
| `AppShell.svelte` | Общий каркас экрана: десктопная 3-зонная боковая панель, мобильная шторка (с нативным CSS-откатом `:has(#fe-sidebar:checked)` без JS), синхронизированный скроллер `<main>` и сброс прокрутки при смене раздела. |
| `CollapsingHeader.svelte` | Многорядная шапка с синхронизацией прокрутки `1:1`, закрепляемым средним рядом и плавной шкалой сворачивания. |
| `HeaderSlot.svelte` / `ui/header/` / `ui/sidebar/` | Регистрация фрагментов навигации, контекстных кнопок и секций боковой панели с любой страницы без протечки доменных маршрутов в `src/components/`. |
| `page.svelte.ts` | Контекст `PageState` (`createPageState`, `usePage`) и хук `useHeadSeo`: реактивный стек слоёв SEO, слотов шапки и сайдбара. |
| `PageHead.svelte` | Единственный компонент `<svelte:head>` в корневом `src/routes/+layout.svelte`: рендерит актуальный верх стека `page.seo` на SSR и в браузере без дублей метатегов. |
| `ui/header/PageTitleSlot.svelte` | Автоматический вывод заголовка текущей страницы в шапку из активного слоя `page.seo`. |
| `prefs.ts` / `shell.svelte.ts` | Хранение и чтение предпочтений оболочки (тема, состояние панелей). |

## Стековый контур метаданных — `useHeadSeo` и `PageHead`

Вместо ручных блоков `<svelte:head>` на каждом маршруте приложение монтирует `<PageHead />` один раз в корневом `src/routes/+layout.svelte`, а страницы, экраны ошибок и модальные окна регистрируют свои метаданные вызовом `useHeadSeo`:

```svelte
<script lang="ts">
  import { useHeadSeo } from '#components/shell/index.js'

  let { data } = $props()

  // Поддерживаются как статические объекты, так и реактивные геттеры:
  useHeadSeo(() => ({
    title: data.card ? `${data.card.title} — Каталог` : 'Карточка',
    description: data.card?.summary,
    ogType: 'article',
    image: data.card?.coverUrl,
  }))
</script>
```

### Ключевые свойства

1. **Стек слоёв (страница → модалка → возврат)**:
   - базовый слой задаётся в `createPageState({ siteName, defaultTitle, defaultDescription, locale })`;
   - страница кладёт свой слой поверх базового, а открытая поверх неё модалка — свой слой поверх страницы; при закрытии модалки верх стека мгновенно возвращается к слою страницы.
2. **Полное совпадение SSR и гидратации**:
   - регистрация выполняется синхронно при инициализации компонента до рендера соседнего `<PageHead />`, а снятие слоя — через teardown `$effect(() => () => unregister())` (а не `onDestroy`, который на SSR срабатывал бы раньше рендера `<PageHead />`).
3. **Защита от гонки размонтирования Svelte 5 при клиентской навигации**:
   - внутренние массивы слоёв хранятся в обычных массивах вне прокси `$state` с монотонным счётчиком ревизии, поэтому teardown старой страницы внутри одного пакета обновлений (`is_destroying_effect` / `old_values`) никогда не затирает слой уже смонтированной новой страницы.
4. **Чистая уборка метатегов между маршрутами**:
   - если у следующего маршрута нет `description`, `image` или `noindex`, соответствующие `<meta>` удаляются из `<head>`, а `robots` возвращается к `index, follow`.
