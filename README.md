# Пакеты опциональных модулей modals-kit

Устанавливаются через `npm run mod -- add <name>` или переменную `MODULES=<name>` при сборке.

Операции «Диска» на отдельных страницах обёрнуты в `DriveOperationPage`: при `data.fact`
показывается `<Acl>` вместо формы, поэтому гость не видит админский контрол (модалки
защищены так же).
